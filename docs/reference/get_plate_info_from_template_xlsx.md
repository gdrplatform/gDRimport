# Get plate info from template xlsx

Get plate info from template xlsx

## Usage

``` r
get_plate_info_from_template_xlsx(template_file, Gnumber_idx, idx)
```

## Arguments

- template_file:

  character, file path(s) to template(s)

- Gnumber_idx:

  index with Gnumber data

- idx:

  template file index

## Value

list with plate info
