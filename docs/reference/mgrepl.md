# grep wrapper to support multiple patterns

grep wrapper to support multiple patterns

## Usage

``` r
mgrepl(patterns, x, do_unlist = TRUE, ...)
```

## Arguments

- patterns:

  charvec with patterns to be checked

- x:

  charvec with data

- do_unlist:

  logical_flag unlist the final results?

- ...:

  additional argument

## Value

list of charvec with grep output
