# for each drug create a Gnumber and Concentration information for each well

for each drug create a Gnumber and Concentration information for each
well

## Usage

``` r
save_drug_info_per_well(trt_info, trt_gnumber_conc, wb, idfs)
```

## Arguments

- trt_info:

  list with treatment info

- trt_gnumber_conc:

  list with treatment data

- wb:

  pointer to xlsx workbook

- idfs:

  charvec with identifiers

## Value

`NULL` invisibly.
