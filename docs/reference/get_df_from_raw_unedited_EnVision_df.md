# Get final results (as a data.table) from raw unedited EnVision data.table

Get final results (as a data.table) from raw unedited EnVision
data.table

## Usage

``` r
get_df_from_raw_unedited_EnVision_df(df, n_row, n_col, barcode_col)
```

## Arguments

- df:

  raw data.table

- n_row:

  number of rows

- n_col:

  number of columns

- barcode_col:

  column number for barcode data

## Value

data.table derived from EnVision data
