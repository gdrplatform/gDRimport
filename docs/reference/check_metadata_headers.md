# Check whether metadata headers are correct and make fixes if needed

Check whether metadata headers are correct and make fixes if needed

## Usage

``` r
check_metadata_headers(corrected_names, df_name)
```

## Arguments

- corrected_names:

  a charvec with corrected colnames of df

- df_name:

  a name of data.table ("" by default)

## Value

a charvec with corrected colnames of df
