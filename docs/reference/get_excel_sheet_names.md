# get Excel sheets names for a charvec of files for non-Excel files return 0

get Excel sheets names for a charvec of files for non-Excel files return
0

## Usage

``` r
get_excel_sheet_names(fls)
```

## Arguments

- fls:

  charvec with file pathsa

## Value

list with one element per file with sheet names or 0 (for non-Excel
file)
