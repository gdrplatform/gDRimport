# Read EnVision file

This function reads file from the EnVision Workstation

## Usage

``` r
read_in_EnVision_file(file, nrows, seps)
```

## Arguments

- file:

  input file from EnVision

- nrows:

  maximum number of file rows to be processed

- seps:

  potential field separators of the input file

## Value

list with one element per EnVisoin input file
