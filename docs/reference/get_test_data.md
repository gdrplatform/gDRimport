# get primary test data

get primary test data

## Usage

``` r
get_test_data()
```

## Value

object class "gdr_test_data" with with input data
(manifest/template/result paths) and related reference data (qs2 file
paths)

## Examples

``` r
get_test_data()
#> class: gdr_test_data 
#> slots: manifest_path result_path template_path ref_m_df ref_r1_r2 ref_r1 ref_t1_t2 ref_t1
```
