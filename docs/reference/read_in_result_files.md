# Read in results files

Read in results files

## Usage

``` r
read_in_result_files(results_file, results_filename, headers)
```

## Arguments

- results_file:

  data.table, with datapaths and names of results file(s) or character
  with file path of results file(s)

- results_filename:

  charvect with file names

- headers:

  list of headers identified in the result files

## Value

data.table with results data
