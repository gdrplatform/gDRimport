# read in Tecan data

read in Tecan data

## Usage

``` r
read_in_results_Tecan(results_file, results_sheets, headers)
```

## Arguments

- results_file:

  string, file path to a result file

- results_sheets:

  template sheet names

- headers:

  list of headers identified in the manifest

## Value

data.table derived from Tecan data
