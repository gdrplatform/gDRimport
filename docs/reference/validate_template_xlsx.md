# Validate template xlsx data

Validate template xlsx data

## Usage

``` r
validate_template_xlsx(template_file, template_filename, template_sheets, idx)
```

## Arguments

- template_file:

  character, file path(s) to template(s)

- template_filename:

  character, file name(s)

- template_sheets:

  template sheet names

- idx:

  template file index

## Value

`NULL` invisibly.
