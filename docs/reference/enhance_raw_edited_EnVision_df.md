# Enhance raw edited EnVision data.table

Enhance raw edited EnVision data.table

## Usage

``` r
enhance_raw_edited_EnVision_df(df, barcode_col, headers)
```

## Arguments

- df:

  raw data.table

- barcode_col:

  column number for barcode data

- headers:

  list with the headersa

## Value

data.table derived from EnVision data
